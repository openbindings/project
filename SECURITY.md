# Security policy

This repository contains release-selection data and GitHub Actions workflows.
Security issues can include unsafe workflow behavior, untrusted-ref execution,
credential exposure, or a cohort record that misidentifies the commits tested.

To report a sensitive issue privately:

- Email `hello@openbindings.com`.
- Contact Matthew Clevenger
  [@clevengermatt](https://github.com/clevengermatt).

For nonsensitive issues, open a public issue. Include the affected workflow or
cohort, impact, reproduction steps, and suggested remediation when available.
Please allow the maintainers to coordinate a fix before public disclosure.
