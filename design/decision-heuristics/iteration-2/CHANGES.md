# Iteration 2 close: draft 2 to draft 3

The five preserved iteration-2 reviews were read with the handoff triage.
This revision applies their verifiable findings while correcting several
assumptions in the triage against the pinned API source.

Applied:

- Separate the general procedure from evaluator-specific replays. Define
  charter vocabulary, consumer versus audience, publication and contract.
- Replace the default-to-shared tie-break with ownership and split records;
  a local decision cannot override a current class restriction.
- Give authority its own precedence. Remove the invented universal ladder
  and automatic host-value-model substitution. Track silence, out-of-scope,
  unread sources, and reference adoption distinctly.
- Make confidence depend on deciding and neutralizing premises, including
  provisional detailed tests. Distinguish ratified headings from operational
  proposals. Confidence and held status are independent.
- Correct rule 13's bounding test, add pay-for-use and reversible-deferral
  proposals, and make optional additions obey the same consumer test.
- Define correct use without assuming floating point associativity, letting
  a new disclaimer erase a contract, or counting ignored flags as correct use.
- Freeze authority and audience provenance; proposed loop text stays proposed
  in later iterations. Record all applicable claims before selecting a reason.
- Record edit dependencies, group cyclic choices, rerun dependents on reversal,
  and count repeated arguments without reopening. Stability does not preserve
  a disproved answer.
- Limit silent local retention to unflagged high rows. No silence ratifies
  policy or authorizes landing. Make batch responses concrete and cheap.
- State boundary checks, source gaps, charter amendments, core dependencies,
  held incomplete features, and how Core loops produce ruling packages.
- Add three worked cases outside the evaluator.

Corrections to the proposed apply bin:

- Close currently blocks active calls and establishes CodeClosed; removal is
  a design change, not correction of a method with no observable job.
- Go regexp is a candidate, but silence on dialect is not permission to
  ignore the current class divergence restriction or a bounded alternative.
- Representation-defined numeric kinds would change the baseline's explicit
  value-based law. The example no longer cites its own candidate as proof.
- Decimal decoding and float32 widening are already stated member contracts;
  the procedure does not pretend to derive them as new decisions.
- Confidence is more conservative than the handoff suggested because the
  source ratifies headings, not all the detailed tests added by the loop.

Not adopted:

- Keep all old verdicts and merely repair their citations. The replays test
  whether the procedure permits a defensible outcome; preserving a verdict
  would conceal the evidence corrections above.
- Treat any new case changing an answer as instability. A valid new case
  should change the answer; instability is unexplained flipping.
- Put an unbounded default in the artifact when no safe incumbent exists.
  The review artifact instead carries a held unsupported or incomplete part.
- Change the panel size, models, six-iteration cap, or target to save cost.
  The existing charter remains in force.
