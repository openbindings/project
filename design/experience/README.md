# Product experience

This directory will define cross-surface experience principles and UI-content
patterns for official OpenBindings products.

Expected subjects include truthful state, message anatomy, action labels,
errors and recovery, empty/loading/success moments, progressive disclosure,
keyboard and assistive-technology expectations, motion, density, and
modality-specific guidance for editorial, workbench, OAuth, and terminal
surfaces.

The goal is family resemblance and shared behavior, not pixel or sentence
identity across unlike media.

Current guidance:

- [Interface foundations](foundations.md) separates candidate behavioral
  requirements from deliberately open visual references and expression
  profiles.
- [Machine material and syntax](machine-material.md) defines the stable
  palette, role hierarchy, renderer boundary, and serialization boundary for
  computer-authored material shown to people.
